## About this site

Built with React, TypeScript, Vite, Tailwind CSS and Motion. Every push to `main` is built and published to GitHub Pages by [.github/workflows/deploy.yml](.github/workflows/deploy.yml).

```bash
npm install
npm run dev     # local dev server on http://localhost:3000
npm run build   # production build into dist/
```
